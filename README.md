# Water Treatment Designer

Dashboard pédagogique de dimensionnement d'une filière de traitement de l'eau (coagulation, floculation, décantation, filtration, désinfection).

Page web statique : tout le code est dans `index.html`, sans serveur ni dépendance.

Les formules sont simplifiées à des fins pédagogiques et ne remplacent pas une étude d'ingénierie.
